G.M. AUTOMOTIVE - PROTOTIPO V14 PER IPHONE

CONTENUTO
- index.html: prototipo web per verbali di ritiro e consegna
- manifest.webmanifest: metadati per installazione come collegamento/app web

IMPORTANTE
Questa versione è una DEMO LOCALE: i dati e le foto sono salvati nel localStorage del browser sul dispositivo. Non c'è sincronizzazione con un server, autenticazione, archivio condiviso, invio WhatsApp o controllo documenti.
Non usare per gestire trasporti reali o documenti sensibili.
Le firme sono immagini tracciate sullo schermo, non firme elettroniche qualificate e la loro validità legale va verificata.
Per la pubblicazione pubblica occorre aggiungere backend sicuro, database, storage privato, accessi separati per G.M./clienti/trasportatori, HTTPS, backup e verifiche privacy/sicurezza.

PUBBLICAZIONE
Caricare il contenuto del pacchetto nel repository GitHub gm-automotive (non il file ZIP annidato), quindi configurare GitHub Pages oppure un hosting statico. Questa demo non richiede Node o database.
